# Finance Bot

## Цель
Семейный Telegram-бот учёта финансов. Портфолио-проект для вакансий AI automation.

## Функции MVP
- Расход текстом, голосом, фото чека (ИИ разбирает и ставит категорию)
- Доходы
- Отчёт: доход против месячной цели, расходы по категориям
- Доступ для двух пользователей (я и жена)

## Стек
Node.js + TypeScript, grammY, Supabase, ИИ-API, Whisper, Docker, деплой на мой Ubuntu VPS

## Правила
- Секреты только в .env, .env в .gitignore
- Маленькие шаги, после каждого — проверка и коммит
- Комментарии в коде и README на английском (для портфолио)
- Перед любыми изменениями — сначала план, код только после моего «ок»
- Объясняй решения простыми словами: я учусь
